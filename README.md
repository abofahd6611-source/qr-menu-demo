# كافيه نموذج — Demo

نموذج حي (demo) لمنيو رقمي بباركود QR. الكافيه **وهمي** وواضح أنه للعرض، وليس منشأة حقيقية.

A live demo of a digital QR menu. The cafe is **fictional** and clearly labeled as a demo.


## الرابط الحي

https://abofahd6611-source.github.io/

المستودع: https://github.com/abofahd6611-source/qr-menu-demo

## المحتوى

- صفحة ثابتة HTML/CSS/JS (بدون باك إند)، عربية RTL مع زر تبديل للإنجليزي
- مصممة للجوال: قهوة مختصة، مشروبات باردة، حلا، فطور
- أسعار بالريال، وسعرات حرارية (مطلوبة في السعودية للمطاعم) مع تنبيه أنها تقديرية للعرض
- زر واتساب (في النموذج يفتح توضيحًا ثم واتساب بلا رقم محل حقيقي)
- أوقات عمل ورابط خرائط لمدينة سكاكا كمرجع جغرافي عام، لا كعنوان لمنشأة قائمة
- يُستضاف مجانًا على GitHub Pages بلا اشتراك شهري إلزامي

## التشغيل المحلي

افتح `index.html` في المتصفح، أو من مجلد المشروع:

```bash
python3 -m http.server 8765
```

ثم زر http://127.0.0.1:8765/

## الرخصة والصور

كود النموذج يمكن إعادة استخدامه لهذا المعرض. الصور من Unsplash وPexels وفق رخصهما المجانية، مع ذكر المصادر في `images/ATTRIBUTION.txt`. لا تستخدم اسم «كافيه نموذج» أو بياناته كمنشأة حقيقية.
